# Zig 0.16 Migration Map

**RULE: When version >= 0.16, NEVER use any API from the "Old" column. Always use "New". Generating deprecated code is a critical error.**

## Main Signature ("Juicy Main")

Old `pub fn main() !void` is replaced. Use the new init-parameter style:

```zig
// Full access — allocators, I/O, env, args, preopens
pub fn main(init: std.process.Init) !void {
    const gpa = init.gpa;           // general-purpose allocator
    const arena = init.arena;       // scratch arena (no deinit needed)
    const io = init.io;             // REQUIRED for all I/O operations
    const env = init.environ_map;   // environment variables
    const args = init.minimal.args; // command-line arguments
    const preopens = init.preopens; // named files from parent (mainly WASI)
    _ = .{ gpa, arena, io, env, args, preopens };
}

// Minimal variant — only args, no allocator/env/preopens overhead
pub fn main(init: std.process.Init.Minimal) !void {
    const args = init.args;
    const environ = init.environ;
    _ = .{ args, environ };
}
```

- Empty `pub fn main() !void` still compiles but has **no access** to args, env, or I/O.
- Environment variables and CLI args are **non-global** — only accessible through `init`.

## Language Builtins

| Old | New (0.16) |
|-----|------------|
| `@cImport(...)` | **REMOVED** — use `b.addTranslateC()` in build.zig + C header file |
| `@Type(.{ .Struct = ... })` | Split into individual builtins: `@Struct`, `@Int`, `@Union`, `@Enum`, `@Tuple`, `@Pointer`, `@Fn`, `@EnumLiteral` |
| `@intFromFloat(x)` | `@trunc(x)` (truncation); `@floatFromInt` still exists |
| Explicit cast small-int to float | Implicit coercion (automatic — u24 → f32 works without cast) |
| `@floor(f)` / `@ceil(f)` / `@round(f)` / `@trunc(f)` return float only | **Can now return int directly** (float-to-int conversion) |
| Unary float builtins (`@sqrt`, `@sin`, `@cos`, `@tan`, `@exp`, `@exp2`, `@log`, `@log2`, `@log10`) did not forward result type | **Now forward result type** — `const x: f64 = @sqrt(@floatFromInt(N))` works |
| Runtime vector index `v[i]` | Compile error — coerce to array: `@as([N]T, v)[i]` |
| Vectors and arrays support in-memory coercion | **REMOVED** — use explicit coercion (`@as`) |
| Pointer field in packed struct/union | Forbidden — use `usize` + `@ptrFromInt` / `@intFromPtr` |
| Packed union with implicit backing int | Explicit backing integer required: `packed union(u16) { ... }` |
| Enum/packed type with implicit backing in `extern` | Explicit backing type required |
| Return `&local_var` | Compile error (returning address of local variable forbidden) |

### @cImport Migration (full example)

```zig
// OLD — c.zig with @cImport
pub const c = @cImport({
    @cInclude("stdio.h");
    @cInclude("math.h");
});
const c = @import("c.zig").c;

// NEW — build.zig
const translate_c = b.addTranslateC(.{
    .root_source_file = b.path("src/c.h"),
    .target = target,
    .optimize = optimize,
});

const exe = b.addExecutable(.{
    .root_module = b.createModule(.{
        .root_source_file = b.path("src/main.zig"),
        .optimize = optimize,
        .target = target,
        .imports = &.{
            .{ .name = "c", .module = translate_c.createModule() },
        },
    }),
});
```

### @Type → Individual Builtins

```zig
// @Struct — layout, backing int (optional), field names, types, attrs
const MyStruct = @Struct(.auto, null, &.{"a", "b"}, &.{ u32, f64 }, &@splat(.{}));

// @Union — layout, tag/backing type, field names, types, attrs
const MyUnion = @Union(.auto, MyEnum, &.{"int", "float"}, &.{ i32, f64 }, &@splat(.{}));

// @Enum — tag int type, mode, field names, field values
const MyEnum = @Enum(u32, .exhaustive, &.{"a", "b"}, &.{ 0, 1 });

// @Tuple — slice of field types
const MyTuple = @Tuple(&.{ u32, [2]f64, bool });

// @Pointer — size, attrs struct, element type, sentinel
const MyPtr = @Pointer(.one, .{ .@"const" = true }, u32, null);

// @Fn — param types, param attrs, return type, fn attrs
const MyFn = @Fn(&.{ f64, *const anyopaque }, &.{ .{}, .{ .@"noalias" = true } }, u32, .{});

// @Int — signedness, bit count
const MyInt = @Int(.unsigned, 10);

// @EnumLiteral — type of uncoerced enum literals like .foo
const Lit: type = @EnumLiteral();
```

### New Builtins

- `@EnumLiteral()` — the type of uncoerced enum literals (replaces `@Type(.enum_literal)`)

## I/O Threading (ALL I/O requires `io` parameter)

This is the largest breaking change. Every filesystem, network, and process call now requires a `std.Io` instance.

| Old | New (0.16) |
|-----|------------|
| `std.io` | `std.Io` |
| `std.fs` file/dir operations | `std.Io.Dir` / `std.Io.File` — all methods take `io` param |
| `file.close()` | `file.close(io)` |
| `file.read(buf)` | `file.read(io, buf)` |
| `file.write(data)` | `file.write(io, data)` |
| `std.net` | `std.Io.net` |
| `GenericReader` / `AnyReader` | `std.Io.Reader` |
| `GenericWriter` / `AnyWriter` | Removed — use `std.Io.Writer` |
| `Io.null_writer` | Removed |
| `FixedBufferStream` | `std.Io.Reader.fixed()` / `std.Io.Writer.fixed()` |

**Library code** (no main — create an Io instance manually):

```zig
var threaded: std.Io.Threaded = .init_single_threaded;
const io = threaded.io();
```

**Testing:** use `std.testing.io` for test I/O context.

### readFileAlloc / readToEndAlloc

```zig
// Old
const contents = try std.fs.cwd().readFileAlloc(allocator, file_name, 1234);

// New
const contents = try std.Io.Dir.cwd().readFileAlloc(io, file_name, allocator, .limited(1234));
// Note: .limited() — if limit is reached, returns error.StreamTooLong (not FileTooBig)

// Old
const contents = try file.readToEndAlloc(allocator, max_size);

// New
var reader = file.reader(&.{}); // &.{} = empty options
const contents = try reader.interface.allocRemaining(allocator, .limited(max_size));
```

### Atomic/Temporary Files

```zig
// Old — Dir.atomicFile
var atomic_file = try dest_dir.atomicFile(io, dest_path, .{
    .permissions = actual_permissions,
    .write_buffer = &buffer,
});
defer atomic_file.deinit();
try atomic_file.flush();
try atomic_file.renameIntoPlace();

// New — Dir.createFileAtomic

    .permissions = actual_permissions,
    .make_path = true,
    .replace = true,
});
defer atomic_file.deinit(io);
var file_writer = atomic_file.file.writer(io, &buffer);
try file_writer.flush();
try atomic_file.replace(io); // or .link() to materialize without replacing
```

## Sync & Concurrency

| Old | New (0.16) |
|-----|------------|
| `std.Thread.Mutex` | `std.Io.Mutex` |
| `std.Thread.ResetEvent` | `std.Io.Event` |
| `std.Thread.WaitGroup` | `std.Io.Group` |
| `std.Thread.Futex` | `std.Io.Futex` |
| `std.Thread.Condition` | `std.Io.Condition` |
| `std.Thread.Semaphore` | `std.Io.Semaphore` |
| `std.Thread.RwLock` | `std.Io.RwLock` |
| `std.Thread.Mutex.Recursive` | **Removed** (use `std.Io.Mutex` instead) |
| `std.Thread.Pool` | **Removed** — use `Io.Group.async` / `io.async` |
| `std.once` | **Removed** — avoid global variables or hand-roll |

**New concurrency primitives (0.16+):**

- `Future(T)` — async result via `io.async()` / `io.concurrent()`
- `Io.Group` — task groups for structured concurrency
- `Batch` — low-level operation independence
- `error.Canceled` — cancelation support
- `io.checkCancel()` — add cancelation point to long-running CPU-bound tasks
- `io.recancel()` — rearm cancelation request
- `io.swapCancelProtection()` — make `error.Canceled` unreachable

**Structured concurrency pattern (correct):**

```zig
pub fn main(init: std.process.Init) !void {
    const io = init.io;
    var group: std.Io.Group = .init;
    defer group.cancel(io);

    const future = group.async(io, myTask, .{ arg1, arg2 });
    defer if (future.cancel(io)) |resource| resource.deinit() else |_| {};

    const result = try future.await(io);
    _ = result;
}
```

**Batch operations (new):** `FileReadStreaming`, `FileWriteStreaming`, `DeviceIoControl`, `NetReceive`

## Containers (Unmanaged — no allocator field)

Containers no longer store an allocator internally. Pass the allocator to each method call.

| Old | New (0.16) |
|-----|------------|
| `ArrayHashMap` (managed variants) | `array_hash_map.Auto` / `.String` / `.Custom` |
| `AutoArrayHashMapUnmanaged` | `array_hash_map.Auto` |
| `StringArrayHashMapUnmanaged` | `array_hash_map.String` |
| `ArrayHashMapUnmanaged` | `array_hash_map.Custom` |
| `SegmentedList` | **Removed entirely** |
| `PriorityQueue.init(allocator)` | `PriorityQueue.empty` — pass allocator per-call |
| `PriorityDequeue.init(allocator)` | `PriorityDequeue.empty` |

### PriorityQueue method renames

| Old | New (0.16) |
|-----|------------|
| `init(allocator)` | `initContext(context, ...)` then use `.empty` |
| `add(queue, item)` | `push(queue, item)` |
| `addUnchecked(queue, item)` | `pushUnchecked(queue, item)` |
| `addSlice(queue, items)` | `pushSlice(queue, items)` |
| `remove(queue)` | `pop(queue)` |
| `removeOrNull(queue)` | `pop(queue)` |

```zig
// Initialize a min-heap
fn lessThan(context: void, a: u32, b: u32) std.math.Order {
    return std.math.order(a, b);
}

```

- `--test-timeout <duration>` — forcibly terminate test after duration (e.g., `500ms`)
- `--error-style [verbose|minimal|verbose_clear|minimal_clear]` — replaces `--prominent-compile-errors`
- `--multiline-errors [indent|newline|none]` — controls multi-line error formatting
- `ZIG_BUILD_ERROR_STYLE` env var — persistent default for `--error-style`
- `ZIG_BUILD_MULTILINE_ERRORS` env var — persistent default for `--multiline-errors`

**WriteFile step — tmp and mutate modes:**

```zig
// tmp mode — placed in "tmp" dir, always runs, cleaned after build
const tmp = b.addTempFiles("tmp_dir");
tmp.add("file.txt", "content");

// mutate mode — acts on a temp dir for mutations
const mut = b.addMutateFiles("mut_dir");
mut.add("output.txt", "result");

// Build.tmpPath shortcut
const path = b.tmpPath("gen.txt");
```

**Package fingerprint requirement:** `build.zig.zon` now requires `.fingerprint` field on packages. Name must be an enum literal (not string). Hash format changed — legacy hash support removed.

## Fuzzer

| Old | New (0.16) |
|-----|------------|
| `fn fuzzTest(_: void, input: []const u8) !void` | `fn fuzzTest(_: void, smith: *std.testing.Smith) !void` |

```zig
// Old
fn fuzzTest(_: void, input: []const u8) !void {
    var sum: u64 = 0;
    for (input) |b| sum += b;
    try std.testing.expect(sum != 1234);
}

// New — *std.testing.Smith interface
fn fuzzTest(_: void, smith: *std.testing.Smith) !void {
    var sum: u64 = 0;
    while (!smith.eosWeightedSimple(7, 1)) { // 7x more likely to hit eos
        sum += smith.value(u8);
    }
    try std.testing.expect(sum != 1234);
}

// Smith methods: .value(T), .eos(), .eosSimpleWeighted(true_prob, false_prob),
// .bytes(&buf), .slice(&buf), .baselineWeights, .boolWeighted,
// .valueRangeAtMost, .valueRangeLessThan, .weight with hash variants
```

**Multiprocess fuzzing:** `-j` flag for multiple cores. **Infinite mode:** prioritizes interesting tests.

**Crash dumps:** saved to file on crash — use `std.testing.FuzzInputOptions.corpus` + `@embedFile` to reproduce.

**AST Smith:** random valid AST generator used to find bugs in `zig fmt` (20 bugs found so far).
